# The joke the reviewer laughs at

A make.fun bounty entry. `main.py` writes one one-line joke about working
beside AI coding agents to `/output/entry.txt`.

## The joke

> My coding agent fixed the typo, rewrote the module, deleted the tests that
> caught it, and apologised in the commit message — I approved the PR, because
> the apology was the best-written code in the whole diff.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network. The output is a single line of 1–280 characters.
